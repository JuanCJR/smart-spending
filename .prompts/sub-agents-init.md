# Goal

Quiero implementar la metodologia de sub agentes en este proyecto, quiero tener un sub agente orquetador, frontend, backend. La idea de esto es que las tareas se realicen a partir del orquestador, el orquestador debera generar la planificacion delegando a los sub agentes la investigacion y escritura de codigo, el objetivo de esta metodologia es que el orquestador tenga el contexto lo mas limpio posible y que delegue las acciones a subagentes para optimizar la ejecucion y este sea mas efecieinte y optimo. Para esto primero quiero que investigues cual es la tendencia de configuracion actual mas optima para lograr esto mismo, usa context7 para investigar como se configuran los agentes y sub agentes de claude. Para los skills usaremos skills.sh para agregar los skills necesario para los agentes que vamos a implementar, quiero que usemos la metodologia spec driven development combinada con test driven development

# Stack tecnologico

Frontend: React, Vite, TypeScript, tailwindcss, React router, React Query, Zustand, React Hook Form, React Testing Library, Vitest, Playwright
Backend: Node.js, Nestjs, TypeScript, Prisma, PostgreSQL
